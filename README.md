# Terraform Azure RG & Storage Automation

This project demonstrates how to automate Azure Resource Group and Storage Account creation using Terraform nested maps and for_each loops.

## Technologies Used
- Terraform
- Microsoft Azure
- VS Code
- GitHub

## Concepts Covered
- Nested Map
- for_each
- Azure Resource Group
- Storage Account
- Infrastructure as Code (IaC)

## Project Workflow
1. Define nested map variables
2. Use for_each loop
3. Create Azure resources automatically
4. Deploy infrastructure using Terraform
